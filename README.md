# Redline Mazda
A Redline Mazda egy modern Mazda használtautó-kereskedés weboldala.
## Fő modellek
- Mazda 2
- Mazda 3
- Mazda 6
- Mazda CX-3
- Mazda CX-30
- Mazda CX-5
- Mazda CX-60
- Mazda MX-5
## Az oldal felépítése
- Főoldal
- Eladó autók
- Autó részletes adatlap
- Modellek
- Finanszírozás
- Autóbeszámítás
- Rólunk
- Kapcsolat
## Fő funkciók
- Autók keresése és szűrése
- Részletes műszaki adatok
- Képgaléria
- Ár és futásteljesítmény
- Kapcsolatfelvétel
- Ajánlatkérés
- Admin felület az autók kezeléséhez
## Design
Modern, prémium Mazda stílus:
- piros
- fekete
- fehér
- nagy autóképek
- lekerekített elemek
- mobilbarát kialakítás
